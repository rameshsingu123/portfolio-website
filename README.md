# Ramesh Singu — Portfolio

A responsive, dark-themed static portfolio built with plain HTML, CSS, and JavaScript. This is independent portfolio work; it is not affiliated with or endorsed by any employer named on the page.

**Independent portfolio project, public on GitHub. Not deployed enterprise or customer system.**

## Files

- `index.html` — semantic page content
- `style.css` — responsive styles
- `script.js` — accessible mobile navigation toggle

## Local preview

Open `index.html` directly in a browser, or run a local static server from this directory:

```sh
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

No build step, framework, external asset, tracker, or package installation is required.
